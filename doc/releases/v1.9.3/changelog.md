# QuickRec Full v1.9.3 变更日志

## 2026-07-29

### 新增

- 新增片段边缘手柄裁剪和精确源入点、源出点输入。
- 新增工具栏、`Ctrl+B` 和右键菜单三种片段分割入口。
- 新增关联视频与音频联合裁剪、联合分割和身份不变量。
- 新增固定全局波纹影响预览、冲突阻止和冲突片段定位。
- 新增轨道锁及剪辑命令禁用规则。
- 新增 timeline schema v2 和 v1 到 v2 延迟原子迁移。
- 新增独立 `QuickRecCLI.exe` 及 doctor、record、probe、项目/时间线校验和
  editing smoke 命令。
- 新增应用事件、项目保存协调、录制只读守卫、单实例和时间线媒体运行时服务。

### 改进

- 剪辑规则从窗口协调层下沉到可测试的领域服务。
- 保存失败时保持 UI、内存、历史栈和磁盘状态一致，并支持重试或放弃。
- 外部文件修改支持取消、恢复副本和重新加载安全分支。
- 裁剪、分割和删除后即时刷新选择、状态摘要、播放头和时间线终点。
- 非零源入点播放、连续分割接缝和长时音画同步使用真实媒体门禁。
- 静止桌面录制复用有效首帧，避免输出 0 帧视频。
- 源码与 frozen 环境统一媒体探测、CLI 合同和证据身份。
- CI 基线测试在真实媒体测试前准备 FFmpeg 与 FFprobe，避免环境依赖缺失。

### 修复

- 修复删除后状态摘要残留已删除片段。
- 修复分割后状态摘要仍显示分割前片段。
- 修复固定全局波纹删除后选择状态没有清空。
- 修复重复启动产生多个 Full 实例和托盘图标。
- 修复部分静止桌面录制可能没有提交有效帧。
- 修复外部冲突重新加载后本地候选状态残留。
