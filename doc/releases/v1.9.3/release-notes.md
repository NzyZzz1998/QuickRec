# QuickRec Full v1.9.3 发布说明

> 当前状态：正式发布
>
> 发布日期：2026-07-29

## 版本定位

v1.9.3 在 v1.9.2 可播放多轨时间线上交付基础剪辑闭环。用户可以对项目片段
执行裁剪、分割和固定全局波纹操作，并在同一剪辑工作台中继续播放确认结果。
本版同时提供独立的内部自动化 CLI，为持续集成、候选包验证和后续导出能力
建立稳定的机器接口。

## 主要变化

### 基础剪辑

- 支持片段左右边缘手柄裁剪和精确数值输入。
- 支持工具栏、`Ctrl+B` 和片段右键菜单三种分割入口。
- 关联视频与音频始终联合裁剪、联合分割，保持素材和关联身份。
- 支持轨道锁、同轨重叠保护、越界保护和最小时长校验。
- 编辑后播放头、时间线总时长、播放终点和素材源范围同步更新。

### 固定全局波纹

- 裁剪、分割和删除前展示影响区间、受影响轨道和片段数量。
- 固定全局波纹会移动所有受影响片段，不提供局部波纹模式。
- 遇到跨越波纹区间的冲突片段时禁止提交，并支持定位冲突。
- 删除只处理时间线片段，不删除项目素材、中央素材记录或原始视频。

### 数据、保存与恢复

- timeline schema 升级为 v2，正式支持非零 `source_start_us`。
- v1 项目仅在第一次成功剪辑时延迟、原子迁移到 v2；只打开或播放不会改写。
- v1.9.2 遇到 v2 数据时保留原始扩展并只读，支持安全回滚。
- 保存失败时正式时间线、历史栈和项目文件保持一致，可重试或放弃候选修改。
- 支持外部文件修改冲突、恢复副本、重新加载、缺失素材和归档只读。

### 内部自动化 CLI

- 发布包新增独立 `QuickRecCLI.exe`。
- 提供 `doctor`、`record`、`probe`、`project validate`、
  `timeline validate` 和 `smoke --suite editing`。
- 使用稳定退出码和 JSON 报告，默认使用隔离 APPDATA、配置、索引和证据目录。
- CLI 直接复用录制、媒体、项目和时间线生产服务，不模拟 GUI 按钮。
- CLI 仍是内部工程工具，不替代托盘、框选、DPI、真实听音和 GUI 验收。

### 稳定性与职责边界

- 新增应用事件、项目保存协调、录制只读守卫和单实例服务。
- 拆分时间线媒体运行时与会话协调职责，统一播放资源释放。
- 静止桌面录制会复用有效首帧，避免生成 0 帧视频。
- 诊断信息补充时间线健康、保存、CLI 和录制性能上下文。

## 已知限制

- 本版不包含变速、转场、滤镜、关键帧、视频变换、正式导出和导出队列。
- 固定全局波纹是唯一波纹模式，不提供局部波纹或关闭波纹。
- 不支持解除关联、音视频分离、独立音频文件、波形和可调音量混合。
- 播放后端正式承诺 QuickRec 自身生成的 H.264/AAC MP4，其他格式仅尽力兼容。
- `QuickRecCLI.exe` 是内部自动化入口，不作为普通用户命令行产品承诺。
- QuickRec Lite 未修改。
