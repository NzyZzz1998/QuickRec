## 3. 版本定位

### 3.1 唯一产品主线

v1.9.3 的唯一产品主线为项目时间线中的基础剪辑闭环：

1. 片段源入点和源出点裁剪；
2. 按播放头分割片段；
3. 视频与关联音频联合裁剪、联合分割；
4. 全局波纹裁剪和全局波纹删除；
5. 轨道锁定与冲突阻止；
6. 撤销、重做、原子保存和保存失败回滚；
7. timeline schema v2 的延迟迁移；
8. 非零源入点和分割边界的真实播放门禁。

### 3.2 工程支撑

本版最多保留两个工程支撑模块：

1. 独立的内部自动化 `QuickRecCLI.exe`；
2. 剪辑职责最小拆分与受影响范围质量门禁。

### 3.3 明确非目标

v1.9.3 不包含：

- 变速、转场、滤镜和关键帧；
- 视频缩放、旋转、位置、透明度和画中画；
- 音量、静音、声像、淡入淡出和波形编辑；
- 正式导出和导出队列；
- 面向普通用户的公开 CLI 产品；
- AI、字幕、摘要、标签和云同步；
- WGC 和新的高刷新率能力；
- QuickRec Lite 改动；
- 数据库；
- 全量架构重写。

## 4. 裁剪交互

### 4.1 操作入口

- 时间线片段提供左右边缘裁剪手柄；
- 选中片段后打开可折叠的右侧“片段属性”检查器；
- 检查器显示素材、轨道、时间线起点、源入点、源出点、有效时长和关联状态；
- 时间线起点只读；
- 源入点和源出点支持 `HH:MM:SS.mmm` 精确输入；
- FPS 可信时额外显示归一化后的源帧编号。

### 4.2 提交与取消

- 手柄拖动期间只更新视觉预览，不写项目文件；
- 鼠标释放后才提交一条原子命令；
- 精确输入点击“应用”或按 Enter 后提交；
- 点击“取消”或按 Esc 恢复操作前状态；
- 连续拖动只形成一条撤销记录；
- 无效候选不得写入内存模型、项目文件或撤销栈。

### 4.3 时间语义

- 左右裁剪均保持所选片段 `timeline_start_us` 不变；
- 裁剪改变 `source_start_us`、`source_duration_us` 和
  `timeline_duration_us`；
- 缩短片段后，通过全局波纹将后续内容前移；
- 延长片段后，通过全局波纹将后续内容后移；
- 裁剪不得超出原始素材范围。

## 5. 分割交互

### 5.1 操作入口

- 工具栏提供“在播放头处分割”按钮；
- 片段右键菜单提供同一操作；
- 快捷键为 `Ctrl+B`；
- 必须先选中片段，且播放头位于片段有效内部。

### 5.2 分割规则

- 分割只处理当前选中的关联片段组；
- 分割本身不改变时间线总时长，也不移动后续片段；
- 播放头位于片段边界或过于接近边界时禁止分割；
- 分割后默认选中右侧新片段；
- 播放头保持在原分割位置；
- 视口和滚动位置保持稳定。

## 6. 最小时长与吸附

### 6.1 最小时长

- 视频或关联音视频片段的最小时长为一个完整源视频帧；
- FPS 缺失或不可信时使用 100 毫秒保守下限；
- 音频片段使用 20 毫秒及合法采样边界作为下限；
- 分割点必须保证左右两侧均满足最小时长；
- 无效操作按钮应禁用，拖动候选应给出明确原因。

### 6.2 吸附

- 沿用其他片段边缘、播放头和可见时间网格吸附；
- 视频裁剪边界必须归一化到合法源帧；
- 按住 Alt 只临时关闭磁性吸附；
- Alt 不得绕过源范围、帧边界或最小时长；
- FPS 不可信时按整数微秒编辑，并提示无法保证帧级精度；
- 关联音频跟随视频边界。

## 7. 全局波纹契约

### 7.1 固定模式

- v1.9.3 固定使用全局波纹；
- 不提供波纹和非波纹模式开关；
- 工具栏持续显示“全局波纹”状态和简要说明；
- 非波纹裁剪或分割只能作为内部里程碑，不能作为 v1.9.3 正式交付。

### 7.2 轨道参与规则

- 所有轨道默认解锁并参与全局波纹；
- 每条轨道标题区提供锁定/解锁操作；
- 锁定轨道不允许编辑和移动；
- 锁定轨道造成冲突时，整次操作失败；
- 不提供每次操作临时选择参与轨道的对话框；
- 轨道锁定状态持久化，并进入撤销、重做和原子保存。

### 7.3 波纹区间算法

- 波纹删除区间为所选关联片段组的 `[开始时间, 结束时间)`；
- 删除后，所有未锁定轨道中从区间结束点开始的片段左移该区间长度；
- 其他轨道存在进入、穿过或覆盖该区间的片段时，操作整体失败；
- 本版不自动裁剪或分割其他轨道上的冲突片段；
- 缩短片段时，原结束点与新结束点之间构成删除区间；
- 延长片段时，原结束点构成插入点，后续片段整体后移；
- 其他片段跨越插入点时，操作整体失败；
- 关联视频和音频视作同一操作组，不互相构成冲突。

### 7.4 影响预览

提交前必须展示：

- 操作时间区间；
- 时间线总时长变化；
- 受影响轨道数量；
- 受影响片段数量；
- 锁定或交叉冲突；
- 可定位的冲突轨道和片段。

一次全局波纹操作必须对应一次撤销记录和一次原子保存。

## 8. 删除片段

- 工具栏、右键菜单和 Delete 键进入同一全局波纹删除流程；
- 删除关联视频或音频中的任一片段时，删除整个关联组；
- 每次删除均要求确认，不提供“不再询问”；
- 确认框显示删除区间、关联片段数和波纹影响范围；
- 存在轨道锁定或区间交叉冲突时禁止确认；
- 删除只修改项目时间线；
- 不删除素材库记录；
- 不删除原始视频文件；
- 删除成功后可通过一次撤销完整恢复。

## 9. 片段身份与关联关系

### 9.1 裁剪

- 保留原 `clip_id`；
- 保留原 `material_id`；
- 保留原 `link_group_id`。

### 9.2 分割

- 左侧片段保留原 `clip_id`；
- 右侧片段生成新的 `clip_id`；
- 左右两侧继续引用同一 `material_id`；
- 左侧关联组保留原 `link_group_id`；
- 右侧关联组生成新的 `link_group_id`；
- 本版不要求父子片段字段；
- v1.9.4 通过片段身份、素材身份和源范围读取最终编排。

### 9.3 关联限制

- v1.9.3 不提供解除音视频关联；
- 关联视频和音频始终原子裁剪、分割、删除、撤销和保存；
- 关联组损坏时禁止单边编辑，并进入只读恢复状态。

## 10. schema v2 与兼容

- 项目顶层 schema 继续保持 v1；
- 仅 `ProjectFile.extensions["quickrec.timeline"]` 升级为 timeline schema v2；
- 打开、查看或播放旧项目不得自动改写文件；
- 仍与 v1 兼容的操作可以继续保持 timeline schema v1；
- 第一次成功执行裁剪、分割、全局波纹删除或轨道锁定时升级为 v2；
- 升级前创建备份；
- 升级、校验和保存必须原子完成；
- 迁移失败时，文件、内存模型和撤销栈均保持原样；
- timeline schema v2 不得自动降级；
- v1.9.2 遇到 v2 时只读保留原始扩展数据；
- 未知字段、项目其他 extensions、素材数据和备份必须往返保留；
- 时间单位继续使用整数微秒；
- 不引入项目级固定 FPS。

## 11. 保存、撤销和外部冲突

- 每次拖动释放、数值应用、分割、删除或轨道锁定都形成一条离散命令；
- 每条命令立即执行原子保存；
- 撤销和重做继续保留最近 50 条；
- 保存失败时，文件、内存模型、选中状态和撤销栈全部回到操作前；
- 保存失败不得出现“界面已修改但磁盘未保存”的半成功状态；
- 保存失败提供持续错误提示、“重试保存”和“打开诊断”；
- 检测到项目被外部修改时禁止覆盖；
- 用户可以重新加载或创建恢复副本。

## 12. 异常和只读状态

- 素材缺失时保留片段、轨道和时间位置；
- 缺失素材禁止裁剪和分割；
- 缺失素材允许重新定位；
- 缺失素材允许用户确认后执行全局波纹删除；
- 重新定位成功后恢复所有引用同一素材 ID 的片段；
- 归档或只读项目只允许查看和播放；
- 未知 timeline schema 只读保留原始数据；
- 损坏时间线进入备份恢复或重建流程；
- 存在待处理保存失败时冻结新的编辑命令；
- 所有禁用状态必须说明原因和恢复方式。

## 13. 播放准确性技术门禁

v1.9.3 继续使用 v1.9.2 的 PyAV 播放链路，不在本版重新选择播放后端。

正式接入剪辑 UI 前必须使用真实媒体验证：

- 非关键帧位置裁剪；
- 非零 `source_start_us` 的首个视频帧；
- 非零 `source_start_us` 的音频起点；
- 分割边界前后重复帧和漏帧；
- 连续片段播放；
- 关联音视频联合分割；
- 中文和空格路径；
- QuickRec 生成的 H.264/AAC 和无声 H.264 MP4；
- 源码环境和 PyInstaller 环境一致性；
- 30 秒和 10 分钟样本；
- 播放、暂停、跳转、项目切换和退出后的资源释放。

量化标准：

| 指标 | 标准 |
| --- | --- |
| 首个视频帧误差 | 不超过一个源视频帧 |
| 分割接缝视频间隙 | 不超过一个源视频帧 |
| 分割接缝重复帧 | 不允许明显重复 |
| 音频目标点之前内容 | 不超过 20 毫秒 |
| 音频接缝重叠或间隙 | 不超过 20 毫秒 |
| 音画绝对偏差 | 不超过 40 毫秒 |
| 10 分钟漂移增量 | 不超过 20 毫秒 |
| 随机跳转 | 不超过 500 毫秒 |
| 暂停响应 | 不超过 200 毫秒 |

若现有 PyAV 链路无法满足门禁：

- 停止正式剪辑 UI 实现；
- 重新评估技术方案；
- 不临时引入第二播放后端；
- 不降级为“仅裁剪”并冒充 v1.9.3 完成。

## 14. 媒体格式边界

- v1.9.3 正式承诺 QuickRec 自身生成的 H.264/AAC MP4；
- 同时承诺 QuickRec 自身生成的无声 H.264 MP4；
- 正式门禁覆盖 30、60 和 120 FPS；
- 外部 MP4 仅尽力兼容；
- 本版不支持 WAV、MP3、AAC 等独立音频文件；
- 裁剪和分割只修改项目数据，不改写原始媒体；
- 有音频的 MP4 生成关联视频和音频片段；
- 无声 MP4 只生成视频片段。

未来“音视频分离”能力只预留数据边界：

- 视频片段和音频片段保留独立 `clip_id`；
- 通过 `link_group_id` 表达当前关联；
- v1.9.3 不提供解除关联、单独裁剪音频、提取音频或独立音频导入；
- 具体版本归属后续重新进入需求池确认。

## 15. 片段属性检查器

- 位于剪辑工作台右侧；
- 可以折叠；
- 不把精确编辑控件继续挤入时间线工具栏；
- 显示素材名、轨道、时间线起点、源入点、源出点、有效时长和关联状态；
- 修改时显示全局波纹影响摘要；
- 支持应用、取消、Enter 和 Esc；
- 重新选中片段时恢复相应属性；
- 在最小窗口和三档 DPI 下保持可操作。

## 16. 原型门禁

- 新建 `doc/releases/v1.9.3/prototype/`；
- 不覆盖 v1.9.2 历史原型；
- 默认展示真实产品界面；
- 提供“开发标注”开关；
- 开启标注后，每个按钮、输入项和状态入口就近说明：
  - 触发条件；
  - 操作结果；
  - 成功反馈；
  - 失败反馈；
  - 禁用规则。

原型至少覆盖：

- 正常剪辑；
- 手柄裁剪预览；
- 精确裁剪面板；
- 播放头分割；
- 全局波纹影响预览；
- 轨道锁冲突；
- 撤销和重做；
- 保存失败；
- 素材缺失；
- 只读项目。

剪辑工作台继续默认最大化。素材面板、预览区和时间线保持可调整布局。
原型必须经用户确认，才能进入 PyQt 正式实现。

## 17. 内部自动化 CLI

### 17.1 产品定位

- 提供独立 `QuickRecCLI.exe`；
- 用于服务开发、CI、Codex 自动验证、候选包检查和发布验收；
- 不作为面向普通用户的完整 CLI 产品；
- 不启动托盘或工作台；
- 不模拟 GUI 按钮；
- 直接复用录制、媒体、项目、时间线和剪辑领域服务。

### 17.2 最小命令

```text
QuickRecCLI doctor --json
QuickRecCLI record --mode fullscreen --duration <秒> --fps <值> --audio <模式>
QuickRecCLI probe <video> --json
QuickRecCLI project validate <project.qrproj>
QuickRecCLI timeline validate <project.qrproj>
QuickRecCLI smoke --suite editing --evidence-dir <路径>
```

本版不公开单独的 `trim`、`split` 或 `delete` 命令，避免形成第二套剪辑产品。

### 17.3 record 边界

- 只支持 `--mode fullscreen`；
- 不提供区域坐标或窗口句柄参数；
- FPS 支持 30、60 和 120；
- 音频支持 `none`、`system`、`mic` 和 `both`；
- 默认 FPS 为 30；
- 默认音频为 none；
- 120 FPS 继续执行现有产品门禁；
- 音频设备不可用时明确失败或跳过；
- 录制后自动执行 FFprobe，并在 JSON 中报告流信息和实际帧率。

### 17.4 隔离规则

- 修改状态的命令必须显式提供隔离工作区和证据目录；
- 缺少隔离参数时拒绝执行；
- 禁止默认读写真实 `%APPDATA%\QuickRec`；
- `smoke --suite editing` 必须复制项目到隔离工作区；
- 不修改输入的原始项目；
- 验证命令默认只读；
- 超时或失败后清理子进程和临时文件；
- 日志不得输出完整环境变量或不必要的隐私路径。

### 17.5 退出码

| 退出码 | 含义 |
| --- | --- |
| 0 | 成功 |
| 2 | 参数或用法错误 |
| 3 | 项目、时间线、媒体或硬件条件验证失败 |
| 4 | 依赖缺失 |
| 5 | 超时 |
| 6 | 取消 |
| 7 | 目录、权限或隔离环境错误 |
| 8 | 未处理的内部错误 |

### 17.6 JSON v1

`--json` 模式的标准输出只能包含一个完整 JSON 对象。成功、失败、取消和超时
使用同一顶层结构：

```json
{
  "schema_version": 1,
  "command": "timeline validate",
  "status": "success",
  "exit_code": 0,
  "started_at": "2026-07-28T00:00:00+08:00",
  "duration_ms": 123,
```

### 17.7 打包

- `QuickRec.exe` 和 `QuickRecCLI.exe` 位于同一正式分发目录；
- 两者共享 `_internal`、FFmpeg、FFprobe 和 PyAV；
- CLI 随正式 ZIP 分发；
- 不为 CLI 创建桌面、开始菜单、托盘或工作台入口；
- 文档将 CLI 标记为内部自动化接口；
- Packaging smoke 必须确认 CLI 不创建 GUI，不读写真实用户目录。

## 19. 性能与规模

继承 v1.9.2 正式基线：

- 最多 8 条视频轨和 8 条音频轨；
- 标准压力规模 100 个片段；
- 标准时间线时长 30 分钟；
- 50 步撤销和重做；
- 默认最大化；
- 恢复窗口最小尺寸 960×640；
- 100%、125% 和 150% DPI。

新增 v1.9.3 门禁：

- 连续执行 100 次裁剪、分割、波纹删除和撤销重做；
- 不产生数据损坏、同轨重叠或孤立关联片段；
- 手柄拖动视觉预览 P95 不超过 50 毫秒；
- 100 片段下，单次编辑提交、原子保存、撤销或重做 P95
  不超过 300 毫秒；
- 超过 100 个片段属于尽力兼容，但不得损坏项目或删除原始视频。

## 20. 质量门禁

- 项目总体语句覆盖率不低于 80%；
- 新增剪辑领域核心模块不低于 85%；
- 手势、属性面板和页面协调模块不低于 80%；
- CLI 命令、隔离和 JSON 合同模块不低于 85%；
- 受影响模块通过 Ruff、Mypy、Compileall 和 `git diff --check`；
- `master`、`test` 和 Pull Request 执行全量测试、静态检查和覆盖率；
- `test`、`master` 和 `v*` tag 额外执行 Packaging smoke；
- Packaging smoke 同时验证两个 EXE、FFmpeg、FFprobe、PyAV 和真实媒体；
- 至少一组测试使用真实打包目录与中文空格路径；
- QuickRec Lite 保持未修改。
