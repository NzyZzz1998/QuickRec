# QuickRec Full v1.9.5 发布说明

> 当前状态：正式发布
>
> 发布日期：2026-07-31
>
> 当前正式版本：v1.9.5

## 版本定位

v1.9.5 在 v1.9.4 正式本地导出闭环上增强剪辑交互和轨道控制。用户可以用
统一快捷键和帧级时间基准编辑时间线，安全解绑或重新关联音视频，并通过带
吸附、落点预览和条件性自动建轨的拖放流程安排素材。

本版不改变最高视频轨全画面覆盖、最多 8 路音频混合、timeline schema v2
和持久导出队列的正式语义，也不引入自由画布、关键帧、代理媒体或新编码器。

## 主要变化

### 统一快捷键与焦点规则

- Space 在剪辑时间线焦点下播放或暂停。
- 左右键逐帧导航，`Shift+左右` 精确移动一秒。
- `Ctrl+B` 分割片段，`Delete` 普通删除并保留空隙，
  `Shift+Delete` 执行全局波纹删除。
- `Ctrl+L` 根据当前片段状态执行解绑或打开严格重新关联候选。
- `Ctrl+Z`、`Ctrl+Y`、Esc 与工具栏、菜单使用同一语义命令。
- 输入框、按钮、列表、菜单和模态弹窗保留 Qt 原生按键行为，避免快捷键误触。

### 音视频解绑与轨道控制

- 合法的一视频一音频关联组可以原子解绑。
- 解绑不改变 `clip_id`、`material_id`、轨道、时间位置、源范围和未知扩展。
- 解绑后视频和音频可独立选择、移动、裁剪、分割和删除。
- 严格重新关联只接受同素材、同时间、同源范围且双方未关联的异类片段。
- 重新关联生成新的 `link_group_id`，失败或保存失败不会留下半成功状态。
- 普通删除和全局波纹删除具有独立入口、影响摘要和撤销记录。

### 智能拖放与条件性自动建轨

- 素材拖动期间展示候选时间、目标轨、帧级吸附来源、关联音频落点和冲突原因。
- 吸附候选包含播放头、片段边缘和帧网格；按住 Alt 只关闭本次吸附。
- 优先复用未锁定、类型兼容且无冲突的已有轨道。
- 所有兼容轨冲突或不存在可用轨道时，才在 8 条视频轨或 8 条音频轨上限内
  条件性自动建轨。
- 带内嵌音频的视频一次创建关联双片段；独立音频只进入音频轨。
- 自动轨和片段通过一次项目保存、一个历史项提交；取消或保存失败不留下空轨。

### 帧级编辑

- 项目使用 30、60 或 120 FPS 的独立编辑基准。
- 新项目继承有效录制 FPS；旧项目按稳定视频证据推导，无法推导时使用 30 FPS。
- 支持 `HH:MM:SS:FF` 和总帧号输入、显示、跳转及标尺刻度。
- 底层继续保存整数微秒，帧换算使用统一有理数和最近帧规则。
- 已有片段后编辑 FPS 锁定，避免时间线边界被重新解释。
- 项目根 schema 仍为 v1，timeline schema 仍为 v2；编辑配置保存在版本化扩展中。

### 三项稳定性治理

- 录制工具栏跟随实际录制屏幕，位于该屏幕中上安全区。
- 成功、取消和中断导出会清理可由 `job_id` 与 `attempt_id` 精确归属的
  `.part.mp4` 和 `.filter.txt`。
- 活跃任务、提交事务、相似文件名、未知文件和用户文件不会被清理。
- CLI 的项目和时间线校验增加编辑 FPS、锁定状态及关联统计。

## 跨版本编辑警告

> v1.9.5 项目与 v1.9.4 及更早版本不保证向下编辑兼容。旧版本可能能够读取
> 项目，但会忽略项目编辑帧率、帧级吸附、解绑/重新关联及新的删除交互。
> 不要在多个版本间反复打开并保存同一生产项目；跨版本操作前请备份
> `.qrproj` 和 `.bak`。

这不表示旧版本一定无法打开项目。项目根 schema 和 timeline schema 没有升级，
未知扩展也会尽力往返保留；但“能够读取”不等于能够正确理解并继续编辑
v1.9.5 的全部语义。

## 已知限制

- 项目编辑 FPS 只支持 30、60、120，已有片段后不可修改。
- 自动建轨仍受视频轨和音频轨分别最多 8 条限制。
- 重新关联只支持严格同素材、同时间、同源范围候选，不提供自由同步偏移。
- 多视频同时有效时仍由最高视频轨全画面覆盖，不提供分屏、画中画、位置、
  缩放、旋转、透明度或关键帧。
- 本版不包含代理媒体、波形、高级音频控制、新编码器、AI、云同步或
  QuickRec Lite 改动。
