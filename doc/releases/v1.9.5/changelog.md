# QuickRec Full v1.9.5 变更日志

> 状态：正式发布
>
> 发布日期：2026-07-31

## 新增

- 新增统一时间线快捷键路由和焦点优先级。
- 新增项目级 30、60、120 FPS 编辑配置。
- 新增 `HH:MM:SS:FF`、总帧号、逐帧与逐秒导航。
- 新增关联音视频原子解绑与严格重新关联。
- 新增普通删除并保留空隙，保留全局波纹删除。
- 新增帧级吸附、落点预览、类型校验和拖动事务。
- 新增条件性自动建轨和关联音视频原子拖入。
- 新增 CLI 编辑配置、关联片段和未关联片段报告。
- 新增可归属导出临时文件清理服务。

## 改进

- Space、分割、删除、波纹删除、关联、撤销和重做统一调用语义命令。
- 输入框、按钮、菜单和模态弹窗不再被时间线快捷键误触。
- 解绑后视频和音频可独立移动、裁剪、分割和删除。
- 重关联候选按轨道距离、轨道顺序和片段 ID 稳定排序。
- 素材拖动优先复用兼容轨，只有无可用轨时才自动建轨。
- 拖动期间展示目标轨、最终时间、吸附来源、关联音频落点和冲突原因。
- 自动建轨与加入片段使用一次保存、一个撤销项和完整失败回滚。
- 标尺、输入和导航统一使用项目编辑 FPS，底层继续保存整数微秒。
- 录制工具栏按真实全屏输出或录制矩形选择目标屏幕，并位于中上安全区。
- 成功、取消和启动中断后的导出仅清理精确归属的临时文件。

## 修复

- 修复时间线画布获得焦点时 Space 未触发播放/暂停。
- 修复 `Delete` 只有全局波纹语义、无法保留空隙。
- 修复素材拖放只能依赖预建兼容轨且失败反馈过晚。
- 修复录制工具栏依赖主显示器定位。
- 修复录制工具栏宽度动画结束后回落到屏幕垂直中部。
- 修复强制结束导出后可归属 `.part.mp4` 和 `.filter.txt` 未安全回收。
- 修复若干片段检查器和影响确认框的历史乱码文本。

## 数据与兼容

- 项目根 schema 保持 v1。
- timeline schema 保持 v2。
- 项目编辑配置保存于版本化 `quickrec.editing` 扩展。
- 只打开或播放旧项目不会主动写入编辑配置；第一次成功结构编辑时与时间线
  修改一起原子保存。
- 未知项目扩展和未知字段继续往返保留。
- v1.9.5 与 v1.9.4 及更早版本不保证向下编辑兼容。跨版本操作前必须备份
  `.qrproj` 和 `.bak`，不要在多个版本间反复保存同一生产项目。

## 已知限制

- 重新关联不支持自由同步偏移。
- 自动建轨受视频轨和音频轨分别最多 8 条限制。
- 多视频重叠仍为最高视频轨全画面覆盖。
- 不包含分屏、画中画、视频变换、关键帧、波形、代理媒体、新编码器、AI、
  云同步或 QuickRec Lite 改动。

## 回滚

- 代码和候选包回滚点：`v1.9.4`。
- 回滚时保留项目、备份、素材、缓存、索引、队列和视频。
- 已使用 v1.9.5 编辑的项目优先使用升级前备份在 v1.9.4 中继续编辑。
