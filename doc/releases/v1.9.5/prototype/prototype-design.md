## 2. 原型目标

本原型不是单独展示一个新页面，而是在完整 QuickRec Full 工作台上演示 v1.9.5 的新增交互：

1. 统一播放、分割、删除、解绑、撤销和帧导航快捷键。
2. 区分普通删除与全局波纹删除。
3. 支持关联音视频解绑，并演示严格重新关联候选。
4. 演示素材拖入时间线时的吸附、落点预览、类型校验和条件自动建轨。
5. 以 30、60、120 FPS 项目编辑帧率展示帧级时间。
6. 保留 v1.9.4 导出与更早版本页面，并明确每项能力的版本来源。
7. 为每个产品控件提供可直接用于开发和测试的完整交互合同。

## 3. 使用方式

### 3.1 普通产品视图

直接打开原型后，默认显示项目的独立剪辑工作台。可以操作素材、播放区、时间线、设置、诊断和导出等现有入口。

### 3.2 开发标注

点击顶部 **开发标注**：

- 每个产品控件显示蓝色编号。
- 点击任一编号控件，右侧显示该控件的完整交互合同。
- 标注模式只解释行为，不真正执行产品操作，避免读规则时误改演示状态。

每份控件合同必须包含：

| 字段 | 说明 |
| --- | --- |
| 首次加入 | 该按钮、菜单、输入项或状态入口首次出现在哪个版本 |
| 后续优化 | 后续版本对该控件的行为、反馈、范围或视觉做过哪些调整 |
| 触发条件 | 用户何时可以发起操作 |
| 即时结果 | 点击、输入或拖动后界面立即发生什么 |
| 成功反馈 | 服务成功后界面、内存和持久化状态如何变化 |
| 失败反馈 | 校验、媒体、保存或系统调用失败时如何反馈和回滚 |
| 禁用规则 | 录制中、只读、未知版本、轨道锁定等情况下何时不可用 |
| 取消 / 关闭 | 用户取消、关闭或按 Esc 后保留什么、恢复什么 |
| 数据影响 | 是否写项目、素材索引、配置、导出队列或真实文件 |
| 撤销 / 恢复 | 是否进入 Undo/Redo，失败时如何恢复 |
| 快捷键 | 固定快捷键、焦点边界及无快捷键说明 |

## 5. v1.9.5 关键控件合同

以下是本版新增或行为发生明显变化的控件。原型中的其他历史按钮同样可通过 **开发标注** 查看完整合同。

| 控件 | 快捷键 | 主要结果 | 数据与撤销 |
| --- | --- | --- | --- |
| 播放 / 暂停 | `Space` | 在剪辑画布拥有操作上下文时切换播放状态 | 不写项目；输入、按钮、菜单、弹窗拥有焦点时不得触发 |
| 上一帧 | `Left` | 按项目编辑帧率向前一帧 | 只移动播放头；`Shift+Left` 向前 1 秒 |
| 下一帧 | `Right` | 按项目编辑帧率向后一帧 | 只移动播放头；`Shift+Right` 向后 1 秒 |
| 分割 | `Ctrl+B` | 在播放头位置分割选中片段或关联组 | 形成一条可撤销命令；边界不足一帧时拒绝 |
| 删除 | `Delete` | 删除片段或关联组并保留原时间空隙 | 原子保存，可撤销；不删除素材和真实视频 |
| 删除菜单 | 无 | 展示普通删除与全局波纹删除的差异 | 只改变菜单状态，不写项目 |
| 全局波纹删除 | `Shift+Delete` | 预检全部轨道影响，确认后删除并整体前移 | 原子保存，可撤销；冲突时零副作用 |
| 解绑 | `Ctrl+L` | 清空双方 `link_group_id`，其他身份与时间不变 | 成对原子提交，可撤销 |
| 重新关联 | `Ctrl+L` | 只接受一对一、同素材、同源范围、同时间位置的严格候选 | 生成新关联组，可撤销；无候选时不写项目 |
| 视频轨 | 无 | 新增视频轨 | 轨道上限 8；与触发拖放组成同一撤销事务 |
| 音频轨 | 无 | 新增音频轨 | 轨道上限 8；与触发拖放组成同一撤销事务 |
| 项目编辑帧率 | 无 | 展示 30 / 60 / 120 FPS 项目时间基准 | 写 `quickrec.editing` 扩展；不改变源媒体和输出 FPS |
| 专注时间线 | 无 | 收起项目素材区和预览区，扩大轨道画布 | 只改变进程内界面状态 |
| 缩小 / 放大 / 适配 | 无 | 改变时间线比例或适配完整内容 | 不改变片段时间与项目数据 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` | 回退或恢复最近离散命令 | 模型、界面、历史和磁盘保持一致 |
| 素材卡拖放 | `Esc` 取消 | 显示目标轨、吸附点、帧时间和自动建轨候选 | 只有放下并保存成功后才写项目 |

## 6. 智能拖放规则

原型覆盖以下状态：

1. **拖入已有轨**：类型相容、无重叠、轨道未锁定时显示蓝色落点。
2. **自动新建视频轨**：所有合适视频轨均冲突但尚未达到 8 轨时，提出新建视频轨候选。
3. **自动新建音视频轨**：带内嵌音频的视频需要成对进入，双方现有轨均无合法落点时提出成对建轨。
4. **无效落点**：轨道类型错误、锁定、重叠、素材缺失或项目不可写时显示红色拒绝反馈。
5. **轨道上限**：视频或音频达到 8 轨时不得继续自动建轨。
6. **取消**：拖动中按 `Esc` 或离开有效画布后，不创建片段、不建轨、不写项目。
7. **原子性**：自动建轨与放入片段必须是同一命令；任一步保存失败都一起回滚。

## 7. 关联音视频规则

### 7.1 解绑

- 只允许恰好包含一条视频和一条音频的有效关联组。
- 解绑只清空两条片段的 `link_group_id`。
- `clip_id`、`material_id`、轨道、时间位置、时长和源范围保持不变。
- 解绑后两条片段可以独立选择、移动、裁剪、分割和删除。
- 任意校验或保存失败必须恢复整个关联组，不能出现单边解绑。

### 7.2 重新关联

- 当前片段必须未关联。
- 候选必须一对一、同素材、同时间位置、同时长、同源范围且类型互补。
- 多候选、模糊候选和零候选都不得自动猜测。
- 成功后为双方生成新的 `link_group_id`。
- 素材缺失不阻止解绑，但重新关联需要可验证身份信息。

## 8. 删除语义

### 8.1 普通删除

- `Delete` 删除选中片段或完整关联组。
- 其他片段的时间位置逐字保持。
- 删除区间成为空隙。
- 不删除项目素材引用、中央素材索引或真实视频。

### 8.2 全局波纹删除

- `Shift+Delete` 进入全局影响预检。
- 预检必须列出删除区间、锁定轨冲突、受影响片段和新总时长。
- 用户确认后才一次性提交。
- 任意轨道冲突或保存失败时整体回滚。

## 9. 帧级时间与焦点优先级

### 9.1 时间基准

- 项目编辑帧率仅允许 30、60、120 FPS。
- 底层数据继续使用整数微秒。
- UI 显示格式为 `HH:MM:SS:FF`。
- 一帧换算、输入校验、导航和吸附必须使用同一个转换服务。
- 变更编辑帧率只改变表达与吸附网格，不改变源视频和导出设置。

### 9.2 快捷键焦点优先级

从高到低：

1. 系统模态弹窗。
2. 文本输入、下拉框、按钮、菜单和列表。
3. 当前拖动、裁剪或候选事务。
4. 时间线画布。
5. 应用级导航。

因此：

- 焦点在按钮上时，`Space` 触发按钮自身，不得切换播放。
- 焦点在输入框中时，字母、方向键和删除键由输入框处理。
- 弹窗打开时，时间线快捷键全部暂停。
- 拖动中 `Esc` 优先取消拖动。
