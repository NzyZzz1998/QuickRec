# QuickRec Lite v0.1 发布说明

发布日期：2026-08-12

状态：正式发布

## 版本定位

QuickRec Lite v0.1 是 Lite 产品线的身份隔离与稳定性收口版本。它不增加录制模式，而是让 Lite 能够与 Full 同机运行，并将已验证的配置、音频、捕获和发布工程能力带回 Lite。

## 主要变化

### 独立产品身份

- 可执行文件和进程改为 `QuickRec-Lite.exe`。
- 产品 ID、单实例、APPDATA、临时目录、默认视频目录、开机启动项、托盘和通知全部使用 Lite 独立身份。
- Full 与 Lite 可以同时运行，互不覆盖配置与数据。

### 安全配置迁移

- 首次启动可选择导入旧配置、使用 Lite 默认设置或取消启动。
- 只复制保存路径与音频模式；快捷键、开机启动和未知字段不迁移。
- 旧配置只读，不移动、不删除、不覆盖。
- 配置使用同目录临时文件、刷新、`fsync` 和原子替换；失败时回滚内存与开机启动状态。

### 录制稳定性

- 默认系统声音设备按设备 ID 优先匹配。
- 双音频使用立体声 `amix`，并按共同起点对齐。
- 静态桌面保留最后有效帧，不生成零帧视频。
- 停止操作采用非阻塞请求和有限等待。
- 固定 60 FPS 帧调度与磁盘估算保持一致。

### Lite 边界收口

- 区域、窗口、倒计时和点击高亮专属运行模块已退出 Lite 源码与打包图。
- 用户可见范围仍只有全屏录制和四种音频模式。
- 不加入 Full 的工作台、素材库、项目、时间线、剪辑、导出队列和诊断中心。

### 发布工程

- 固定 Python 依赖和 FFmpeg 8.0.1 来源、版本与 SHA256。
- 新增 release manifest，记录版本、构建环境、依赖、EXE、FFmpeg、ZIP 和包体积。
- CI 独立覆盖 `lite-master`、`lite-test`、Pull Request 和 `lite-v*` Packaging smoke。

## 验证状态

- 自动化测试、覆盖率、Ruff、Mypy、Compileall、Packaging：通过。
- Full/Lite 同机运行、单实例、迁移、配置事务、静态桌面、快速停止和连续录制：通过。
- 无声和系统声音候选包录制：通过。
- 麦克风与双音频真实候选包录制：通过。

正式发布资产包含 `QuickRec-Lite-v0.1-win-x64.zip` 与 `release-manifest.json`。

## 已知限制

- 仅支持单显示器全屏录制。
- 固定原生分辨率与 60 FPS，不提供 30/60 选择或 120 FPS。
- 展开包约 257.88 MB；体积不是 v0.1 发布阻断项。
- 不提供用户可见诊断中心。

## 回滚

- 代码回滚点：`lite-v0` tag，固定指向 `c15940e`。
- v0.1 配置保存在 `%APPDATA%\QuickRec-Lite`，回滚不会反向写入 Full 配置。
- v0.1 录制文件不会随回滚删除。
