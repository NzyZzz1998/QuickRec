# QuickRec Full v1.9.4 变更日志

## 2026-07-30

### 新增

- 新增不可变、可复现的 `ExportPlan` 及素材指纹校验。
- 新增单工作线程持久导出队列和完整任务状态机。
- 新增工作台“导出”页面、剪辑工作台导出入口、配置对话框、预检、任务详情和
  退出确认。
- 新增最大 4K 正偶数画布及 30、60、120 FPS 输出组合。
- 新增最高视频轨固定覆盖、空白黑场和最多 8 路活动音频动态 `1/N` 混合。
- 新增 FFmpeg 执行、FFprobe 最终验证和同目录原子提交。
- 新增默认安全后缀及显式覆盖备份、事务与崩溃恢复。
- 新增队列暂停、继续、取消、停滞提示、自动重试、手动重试和重启恢复。
- 新增导出结果自动加入中央素材库、入库失败持久重试和显式加入项目。
- 新增 `QuickRecCLI export validate` 与 `export smoke`。
- 新增导出诊断上下文和录制/导出媒体资源互斥。

### 改进

- 工作台、剪辑工作台和 CLI 统一使用同一导出领域服务。
- 输出目标在计划创建和入队时共同预留，避免排队任务产生同名冲突。
- 任务进度区分计划、验证、编码、提交和入库阶段，100% 仅表示正式文件已提交。
- 运行任务异常结束后恢复为 `interrupted`，排队任务保持暂停，防止重启后
  无授权自动编码。
- 项目变化不会污染已冻结任务；素材变化会在运行前给出精确失败原因。
- 诊断和日志使用脱敏路径摘要，不输出完整环境变量。
- 导出配置对话框根据当前屏幕可用区域收敛尺寸，兼容三档 Windows DPI。

### 修复

- 修复未完成队列任务没有预留输出目标，导致后续任务在编码完成后才发生冲突。
- 修复候选文件在提交前目标变化时可能残留。
- 修复显式覆盖取消或失败路径可能留下不一致事务状态。
- 修复导出配置对话框在 150% DPI 或较小可用区域下底栏裁切。
- 修复停滞“继续等待”后计时与进度状态未正确重置。
- 修复入库失败重启后缺少持久重试状态。

### 已知限制

- 单工作线程顺序导出，不提供并发导出或公开高级编码参数。
- 软件编码继续使用 `libx264`。
- `LIMIT-194-01`：极端强制结束 QuickRec 和子 FFmpeg 时可能留下可归属的
  `.part.mp4` 与 `.filter.txt`；不影响旧目标和正式结果，后续版本治理。
