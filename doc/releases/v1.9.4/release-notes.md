# QuickRec Full v1.9.4 发布说明

> 当前状态：正式发布
>
> 发布日期：2026-07-30

## 版本定位

v1.9.4 在 v1.9.3 基础剪辑能力上补齐正式本地导出闭环。用户可以从剪辑
工作台冻结当前 timeline schema v2 状态，创建可复现的导出任务，并通过工作台
中的持久队列查看进度、取消任务、诊断失败、重试以及恢复应用或系统中断的任务。

本版采用单工作线程队列、软件 H.264/AAC 编码、FFprobe 最终验证和同目录原子
提交，优先保证成片正确、旧目标安全和异常状态可解释。

## 主要变化

### 正式本地导出

- 从项目 timeline schema v2 构造不可变 `ExportPlan`，冻结轨道、片段、源范围、
  素材指纹和输出参数。
- 支持正偶数自定义画布，最大 `3840×2160`。
- 支持 30、60、120 FPS；120 FPS 仅允许不超过 `1920×1080` 的画布。
- 视频采用最高有效轨全画面覆盖，时间线空白区输出黑场。
- 支持最多 8 路活动音频，按活动源数量动态使用 `1/N` 增益并输出 48 kHz
  双声道 AAC。
- 正式输出为 H.264/AAC MP4；无音频时间线输出 H.264 MP4。

### 持久导出队列

- 工作台新增“导出”页面，剪辑工作台新增统一导出入口。
- 使用单工作线程顺序执行任务，支持队列暂停、继续、取消、失败诊断和手动重试。
- 任务状态、尝试历史、阶段进度、预计时间、停滞状态和入库结果持久保存。
- 应用或系统中断后，运行任务恢复为 `interrupted`，排队任务保持暂停，必须由
  用户显式重试，不会自动继续编码。
- 已识别的瞬时 FFmpeg 或文件系统错误最多自动重试一次；同一任务最多保留
  5 次尝试。

### 文件与数据安全

- 默认不覆盖已有文件，同名任务使用安全后缀。
- 显式覆盖需要二次确认，并使用备份、事务日志和恢复流程保护旧目标。
- 每次尝试使用独立临时文件；只有 FFprobe 验证通过后才原子提交正式 MP4。
- 运行前重新核对素材指纹，素材移动、删除或变化时阻止执行并说明原因。
- 导出成功后自动加入中央素材库；入库失败不改写“视频已导出”的事实，可持久
  重试且不会重新编码。
- 加入当前项目保持显式操作，不自动改变项目素材关系。

### CLI、诊断与工程门禁

- `QuickRecCLI.exe` 新增 `export validate` 和 `export smoke`。
- CLI、工作台和剪辑工作台共用同一计划、队列、执行、验证和提交语义。
- 诊断信息新增队列摘要、失败阶段、尝试历史、输出验证和覆盖恢复上下文。
- 打包产物同时验证 GUI、CLI、FFmpeg、FFprobe、PyAV 和导出滤镜脚本。

## 已知限制

- 本版仅使用单工作线程，不提供并发导出、任务优先级或拖动排序。
- 使用 `libx264` 软件编码，不接入 NVENC、QSV、AMF 或其他硬件编码器。
- 不公开码率、CRF、GOP、像素格式和滤镜图等高级编码参数。
- 导出任务使用创建时冻结的计划；项目后续变化不会自动改写既有任务。
- 应用或系统中断后的任务不会自动续跑，需要用户显式重试。
- 在导出过程中强制结束 QuickRec 及其 FFmpeg 子进程，可能留下能够按
  `attempt_id` 归属的 `.part.mp4` 和 `.filter.txt`。它们不会成为正式输出，
  不会覆盖旧目标，也不会被后续尝试复用；该问题作为 `LIMIT-194-01` 留待后续
  版本实现安全自动清理。
- 本版不包含硬件编码、云导出、AI、QuickRec Lite 改动或全量架构重写。
