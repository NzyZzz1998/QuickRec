# QuickRec Full v1.9 发布说明

> 当前状态：正式发布
> 发布日期：2026-07-27

## 版本定位

v1.9 为 QuickRec Full 增加本地项目工作区基础。项目用于组织全局素材引用和项目上下文录制，不复制、移动或接管原始视频，也不引入时间线、剪辑、多轨或导出队列。

## 主要变化

### 项目工作区

- 工作台新增“项目”一级页面。
- 支持默认或自定义位置创建项目。
- 支持原地打开外部 `project.qrproj`。
- 支持重命名、说明编辑、归档和恢复。
- 同一素材可加入多个项目，从项目移除不会删除视频或全局素材记录。
- 项目页支持全屏、区域、窗口三种平级录制入口。

### 数据安全

- 使用 `%APPDATA%\QuickRec\projects.json` 维护中央项目发现索引。
- 每个项目使用独立 `project.qrproj` 保存项目详情和素材稳定 ID 引用。
- 项目与中央索引均使用原子写入和有效备份。
- 支持项目缺失重新定位、损坏备份恢复和外部修改冲突保护。
- 无有效备份时保留损坏文件，不创建空项目。

### 安全删除

- 删除项目默认不选择任何原始视频。
- 只有可证明独占且存在的素材允许选择。
- 共享、缺失或归属不确定素材禁止删除。
- 项目文件和选中视频只进入 Windows 回收站。
- 任一步失败都会停止后续操作并显示逐项结果。

### 工程质量

- 项目存储、生命周期、查询、录制协调、恢复和删除逻辑从 UI 中独立。
- 慢速回收站操作在后台线程执行。
- 新模块已纳入 ruff、mypy、coverage、CI 和 packaging 门禁。

## 已知边界

- 不包含素材预览、项目时间线、多轨、剪辑、导出队列、AI 或云同步。
- 不修改 QuickRec Lite。
- 项目只保存素材引用，不复制原始视频。
- 多项目共享状态依赖可读取的本机项目索引；无法证明独占时按“不确定”处理。
