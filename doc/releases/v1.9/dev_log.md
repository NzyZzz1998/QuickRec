## 2026-07-26：D2 项目服务与查询

### 本轮目标

- 把项目生命周期、素材引用和共享判定隔离到服务层。
- 建立项目列表、最近项目、归档和健康状态查询。

### 关键实现

- 新增 `src/services/project_library.py`。
- 创建项目时先写项目文件，再写中央索引；索引失败返回明确部分成功。
- 外部项目只原地登记；相同项目 ID 的新路径必须显式更新。
- 重命名不改变稳定 ID 和物理目录。
- 归档项目为只读，恢复成功后才重新允许修改。
- 写入前比较项目文件修改时间，阻止静默覆盖外部修改。
- 项目素材引用按 `material_id` 幂等，一个素材可属于多个项目。
- 引用分类明确区分 `exclusive`、`shared` 和 `uncertain`。
- 任一登记项目不可读时，无法证明独占的素材降级为“不确定”。
- 新增 `src/services/project_query.py`，提供最近 8 个、活跃、归档、关键词和文件健康查询。
