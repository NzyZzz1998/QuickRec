# QuickRec Full v1.8 发布说明

> 状态：正式发布
> 收口日期：2026-07-26

## 本版定位

v1.8 将 QuickRec Full 从托盘录制工具推进为统一的创作者桌面工作台，并在真实硬件
技术门禁通过后正式提供单显示器 1080p120 全屏录制。素材、设置和诊断能力保持本地化，
不引入项目模型、剪辑、导出队列、AI 或云同步。

## 主要变化

### Full 工作台

- 固定左侧导航统一承接录制、素材库、设置和诊断。
- 工作台全局单实例；关闭只隐藏，托盘退出才结束应用。
- 同一进程内恢复上次页面，首次启动默认进入录制页。
- 工作台发起录制时自动隐藏，保存完成后恢复并显示结果。
- 录制中可重新打开工作台查看只读状态，控制仍由浮动工具栏负责。
- 保存窗口大小和位置，显示环境变化后自动修正到可见区域。
- 设置页使用显式保存，支持保存、放弃、取消和保存失败回滚。
- 完成侧栏、页面、选择器、浮动工具栏、提示和图标的统一视觉改版。

### 1080p120 全屏录制

- FPS 设置提供 30、60、120；新安装仍默认 30。
- 120 FPS 仅用于全屏录制，区域和窗口录制最高 60 FPS。
- 首次启用 120 FPS 时执行约 5 秒真实能力检测。
- 录制前快速校验刷新率、检测缓存、FFmpeg、保存目录和磁盘空间。
- 能力缓存会在显示模式、保存磁盘、CPU/GPU、FFmpeg 或编码配置变化后失效。
- 性能不稳定时正常保存视频，并显示实际平均 FPS、最低 FPS 和稳定性告警。
- 支持无声、系统声音、麦克风和系统声音＋麦克风。
- 修复音频采集与视频首帧固定时间轴偏移，按音轨独立对齐后再混音。

## 已知限制

- 120 FPS 正式承诺仅覆盖单显示器 1920×1080 全屏录制。
- 区域和窗口录制最高 60 FPS。
- 不承诺多显示器、4K、WGC 或硬件编码。
- 120 FPS 能力检测仍使用 dxcam 与 `libx264-superfast`。
- 工作台不包含项目模型、多轨、剪辑、导出队列、素材预览、AI 或云同步。
- 诊断信息只保存在本地，不自动上传。

## 回滚方式

- 代码和发布包直接回滚点：`v1.7`。
- 回滚前如配置中 `fps=120`，先将其改为 `60`。
- 使用 v1.7 tag 或 v1.7 GitHub Release 发布包。
- 不删除 `%APPDATA%\QuickRec\recordings.json`、待入库记录或视频文件。
- 不移动或重写任何历史 tag。
