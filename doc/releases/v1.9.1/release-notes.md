# QuickRec Full v1.9.1 发布说明

> 当前状态：正式发布
>
> 发布日期：2026-07-27

## 版本定位

v1.9.1 为项目工作区补充静态首帧预览和基础素材使用闭环。用户可以在项目中识别素材、查看关键元数据、打开视频或目录，并在项目页与全局素材库之间保持上下文跳转。

## 主要变化

### 项目素材预览

- 项目素材列表提供固定 16:9 首帧。
- 详情区提供 320×180 预览和完整素材元数据。
- 支持未生成、排队、生成中、可用、失败、缓存失效、文件缺失和待关联状态。
- 文件缺失时可保留历史首帧，并叠加明确缺失提示。
- 支持刷新单条预览和批量重建项目预览。

### 素材使用闭环

- 支持从项目页打开视频和所在目录。
- 支持跳转全局素材库并按稳定素材 ID 选中。
- 支持从素材库返回原项目和原素材。
- 预览失败不影响文件操作、项目引用或素材库恢复。

### 缓存与性能

- 首帧缓存位于 `%LOCALAPPDATA%\QuickRec\ThumbnailCache\v1`。
- 缓存使用源文件大小、修改时间和稳定素材 ID 生成指纹。
- 默认上限为 500 MiB，并按最近使用时间清理。
- 最多同时执行两个预览任务，录制主链路优先。
- 工作台隐藏不取消预览；应用退出会停止任务和 FFmpeg 子进程。

## 数据边界

- 不向 `project.qrproj`、`projects.json` 或 `recordings.json` 写入预览路径或任务状态。
- 删除预览缓存不会删除视频、项目或中央素材索引。
- v1.9 项目无须迁移即可使用。

## 已知边界

- 不包含内嵌视频播放器。
- 不包含时间线、多轨、剪辑、导出队列、AI 或云同步。
- 不修改 QuickRec Lite。
